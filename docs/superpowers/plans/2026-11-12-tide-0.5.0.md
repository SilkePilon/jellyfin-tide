# Tide 0.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the 0.5.0 spec (`docs/superpowers/specs/2026-11-12-tide-0.5.0-design.md`):
- the player settings menu (M1) that mirrors the default player's settings;
- the subtitles menu (B) with search and online download;
- the Q1 Spotlight search dialog;
- the F1 · C3 island top bar.

**Architecture:**
- **Player menus:** popovers built on one small primitive (`player/menu.ts`). Settings rows and options come from the stock 12.4 action sheet, which a hidden driver reads and clicks (`player/stockMenu.ts`). Subtitles use session commands plus a new server capability endpoint and Jellyfin's RemoteSearch API.
- **Search:** a lazily created dialog (`search/`) wired to the app-bar search link, `/` and Ctrl/⌘+K, and the stock `#/search` route.
- **Top bar:** CSS on the stock MUI app bar, plus a small labeller for tooltips.

**Tech Stack:**
- Web: TypeScript, Vite, vitest + jsdom.
- Server: C# .NET 10 Jellyfin 12.4 plugin, xUnit.
- End-to-end: Playwright against the local 12.4 container.

## Global Constraints

These apply to every task.

**Surfaces**
- Solid only: panel `#141416`, hover and controls `#2a2a2e`, raised `#3a3a3c`.
- Panel edge: `box-shadow: 0 0 0 1px #2a2a2e, 0 24px 60px rgba(0,0,0,.6)`.
- No `backdrop-filter`, no see-through panels. A dim scrim `rgba(0,0,0,.72)` behind the search dialog is allowed.

**Motion**
- Transform and opacity only, with curve `cubic-bezier(.22,1,.36,1)`. In player CSS this curve is `var(--tide-sp)`; in theme CSS it is `var(--tide-ease)`.
- Never rebuild an animated node per frame.

**Visibility**
- An invisible overlay gets `pointer-events: none`.
- `[hidden]` must win over a component's own `display` (player CSS already has `body.tide .tide-player [hidden] { display: none !important; }`).

**Icons**
- Every new Material Symbols name used as a string literal in `web/src` must be in the font subset.
- After adding one, run `node scripts/icons.mjs` (from `web/`, needs network) and commit `src/theme/fonts/tide-symbols.{woff2,json}`.
- `test/iconFont.test.ts` fails otherwise. If the script cannot reach Google Fonts, stop and report BLOCKED.

**Probed 12.4 facts** (Task 1 writes them into `docs/notes/web-12.4-player.md`)
- **Stock settings sheet:** `.btnVideoOsdSettings` opens `.dialogContainer .actionSheet.opened`. Items are `[data-id]` with `.actionSheetItemText` and `.actionSheetItemAsideText`. Main rows are `aspectratio`, `playbackrate`, `quality`, `repeatmode`, `suboffset` and `stats` (Desktop has more aspect ratios).
- **Submenus:** a submenu marks the current option with a visible `.actionsheetMenuItemIcon`; the others have `style="visibility:hidden"`.
- **Opening** adds `dialogs` to `history.state.usr`.
- **Closing:** Escape, backdrop clicks and outside clicks do **not** close a sheet. `history.back()` closes the newest sheet and stays on `#/video`. Clicking an item closes its sheet itself.
- **Subtitle offset:** `suboffset` creates `.subtitleSync` with `.subtitleSyncSlider` (`min -30`, `max 30`, `step 0.1`). Setting `value` and dispatching `input` and `change` applies it, even while the panel is hidden. The value persists after the panel's close button.
- **App bar:** `.MuiToolbar-root` children are `MuiStack-root` (home link `a[href="#/"]` plus library links), then `MuiBox-root` (SyncPlay, Cast, `a[href="#/search"][aria-label="Search"]`), then `MuiBox-root` (User Menu). This holds on every page. Tide marks the current library with `aria-current="page"`.
- **Search hints:** `GET /Search/Hints?searchTerm=…` returns `{ SearchHints: [{ Id, Name, Type, ProductionYear, RunTimeTicks, Series, IndexNumber, ParentIndexNumber, PrimaryImageTag, AlbumArtist, Album, AlbumId, AlbumPrimaryImageTag, Artists, ChildCount }], TotalRecordCount }`. When `includeItemTypes` is given, people and artists only come back if `Person` / `MusicArtist` are in that list.
- **RemoteSearch:** `GET /Items/{id}/RemoteSearch/Subtitles/{lang3}` returns 200 `[]` without a provider. `GET /Localization/Cultures` returns ~494 cultures with `Name`, `DisplayName`, `TwoLetterISOLanguageName`, `ThreeLetterISOLanguageName`, `ThreeLetterISOLanguageNames`.

```ts
/**
 * Drives the stock 12.4 settings action sheet (`.btnVideoOsdSettings`) while it is hidden, so Tide's settings menu
 * offers exactly what the default player offers on this device (Jellyfin Desktop lists more aspect ratios than web).
 * Probed facts: docs/notes/web-12.4-player.md ("Stock settings sheet").
 */
export interface StockOption { id: string; text: string; aside: string; selected: boolean }
export interface StockMenu {
  /** Main rows (aspectratio, playbackrate, quality, repeatmode, suboffset, stats, ...). */
  rows(): Promise<StockOption[]>;
  /** A row's submenu options; `selected` marks the current one. */
  options(rowId: string): Promise<StockOption[]>;
  pick(rowId: string, optionId: string): Promise<void>;
  /** Click a row that has no submenu (stats, suboffset). */
  run(rowId: string): Promise<void>;
}
export interface SubOffset { get(): number | null; set(seconds: number): Promise<void> }

export const SHEET_TIMEOUT_MS = 1500;
const OPEN = '.actionSheet.opened';

export function readSheet(sheet: Element): StockOption[] {
  return [...sheet.querySelectorAll<HTMLElement>('[data-id]')].map((el) => {
    const mark = el.querySelector<HTMLElement>('.actionsheetMenuItemIcon');
    return {
      id: el.dataset.id ?? '',
      text: (el.querySelector('.actionSheetItemText')?.textContent ?? '').trim(),
      aside: (el.querySelector('.actionSheetItemAsideText')?.textContent ?? '').trim(),
      selected: !!mark && mark.style.visibility !== 'hidden',
    };
  });
}

function waitFor<T>(find: () => T | null | undefined, timeoutMs: number): Promise<T> {
  return new Promise((resolve, reject) => {
    const t0 = Date.now();
    const tick = () => {
      const v = find();
      if (v) { resolve(v); return; }
      if (Date.now() - t0 > timeoutMs) { reject(new Error('stock sheet timeout')); return; }
      setTimeout(tick, 25);
    };
    tick();
  });
}

const openSheets = () => [...document.querySelectorAll(OPEN)];
const newest = (except: Element[]) => openSheets().find((s) => !except.includes(s)) ?? null;
const hasDialogEntry = () => !!(history.state as { usr?: { dialogs?: unknown[] } | null } | null)?.usr?.dialogs?.length;

export function createStockMenu(button: () => HTMLElement | null, timeoutMs = SHEET_TIMEOUT_MS): StockMenu {
  let chain: Promise<unknown> = Promise.resolve();
  const queued = <T>(fn: () => Promise<T>): Promise<T> => {
    const p = chain.then(fn, fn);
    chain = p.catch(() => undefined);
    return p;
  };
  const gone = (sheet: Element) => waitFor(() => (!sheet.isConnected || !sheet.matches(OPEN) ? true : null), timeoutMs);
  /** Close without picking, only through the history entry the sheet added itself (never leaves #/video). */
  const dismiss = async (sheet: Element) => {
    if (sheet.isConnected && sheet.matches(OPEN) && hasDialogEntry()) history.back();
    await gone(sheet).catch(() => undefined);
  };
  /** One hidden drive: every sheet it opened and left open is dismissed afterwards. */
  const drive = <T>(fn: (track: (s: Element) => Element) => Promise<T>): Promise<T> => queued(async () => {
    const mine: Element[] = [];
    document.documentElement.classList.add('tide-stock-hidden');
    try {
      return await fn((s) => { mine.push(s); return s; });
    } finally {
      for (const s of mine.reverse()) await dismiss(s);
      document.documentElement.classList.remove('tide-stock-hidden');
    }
  });
  const openMain = async (): Promise<Element> => {
    const before = openSheets();
    const b = button();
    if (!b) throw new Error('stock settings button missing');
    b.click();
    return waitFor(() => newest(before), timeoutMs);
  };
  const click = (sheet: Element, id: string) => {
    const item = [...sheet.querySelectorAll<HTMLElement>('[data-id]')].find((x) => x.dataset.id === id);
    if (!item) throw new Error(`stock option ${id} missing`);
    item.click();
  };
  const openSub = async (track: (s: Element) => Element, rowId: string): Promise<Element> => {
    const main = track(await openMain());
    click(main, rowId);
    return track(await waitFor(() => newest([main]), timeoutMs));
  };
  return {
    rows: () => drive(async (track) => readSheet(track(await openMain()))),
    options: (rowId) => drive(async (track) => readSheet(await openSub(track, rowId))),
    pick: (rowId, optionId) => drive(async (track) => {
      const sub = await openSub(track, rowId);
      click(sub, optionId);
      await gone(sub);
    }),
    run: (rowId) => drive(async (track) => {
      const main = track(await openMain());
      click(main, rowId);
      await gone(main);
    }),
  };
}

/** Tide's subtitle "Timing": drives the stock offset slider (opened once via the `suboffset` row, kept hidden). */
export function createSubOffset(menu: StockMenu): SubOffset {
  const slider = () => document.querySelector<HTMLInputElement>('.subtitleSync .subtitleSyncSlider');
  return {
    get: () => { const s = slider(); return s ? Number(s.value) || 0 : null; },
    async set(seconds) {
      if (!slider()) {
        await menu.run('suboffset');
        await waitFor(slider, SHEET_TIMEOUT_MS);
      }
      const s = slider()!;
      const v = Math.max(Number(s.min || -30), Math.min(Number(s.max || 30), Math.round(seconds * 10) / 10));
      s.value = String(v);
      s.dispatchEvent(new Event('input', { bubbles: true }));
      s.dispatchEvent(new Event('change', { bubbles: true }));
    },
  };
}
```

```ts
import { h } from '../ui/dom';

/** A popover above the player's control row (Settings, Subtitles). Its right edge lines up with its button's. */
export interface PlayerMenu { el: HTMLElement; open(anchor: HTMLElement | null): void; close(): void; isOpen(): boolean }

/** CSS `right` (px) for a menu in `container` whose right edge should meet `anchor`'s right edge. */
export function rightOffset(container: DOMRect, anchor: DOMRect, gutter = 16): number {
  return Math.max(gutter, Math.round(container.right - anchor.right));
}

export function createMenu(cls: string, label: string, onOpenChange: (open: boolean) => void): PlayerMenu {
  const el = h('div', { class: `tide-pmenu ${cls}`, role: 'dialog', 'aria-label': label, 'aria-hidden': 'true' });
  // Clicks inside never reach the player root (which would toggle play / close menus).
  el.addEventListener('click', (e) => e.stopPropagation());
  let open = false;
  return {
    el,
    open(anchor) {
      const box = el.parentElement;
      if (anchor && box) el.style.right = `${rightOffset(box.getBoundingClientRect(), anchor.getBoundingClientRect())}px`;
      if (open) return;
      open = true;
      el.classList.add('open');
      el.removeAttribute('aria-hidden');
      onOpenChange(true);
    },
    close() {
      if (!open) return;
      open = false;
      el.classList.remove('open');
      el.setAttribute('aria-hidden', 'true');
      onOpenChange(false);
    },
    isOpen: () => open,
  };
}
```

```ts
import { h, icon } from '../ui/dom';
import { createMenu, type PlayerMenu } from './menu';
import type { StockMenu, StockOption } from './stockMenu';
import type { Track } from './tracks';

export const ROW_ICONS: Record<string, string> = {
  audio: 'graphic_eq', aspectratio: 'aspect_ratio', playbackrate: 'speed', quality: 'high_quality', repeatmode: 'repeat', stats: 'info',
};
/** Stock rows Tide shows elsewhere: the subtitle offset is "Timing" in the subtitles menu. */
export const HIDDEN_ROWS = new Set(['suboffset']);
export const BACK_MS = 220;

export interface SettingsDeps {
  stock: StockMenu;
  audio(): { tracks: Track[]; current: number | null };
  pickAudio(index: number): void;
  /** Whether the stock Playback info overlay (`.playerStats`) is showing. */
  statsOn(): boolean;
  /** Fallback: the visible stock settings dialog. */
  openStock(): void;
  onOpenChange(open: boolean): void;
}
export interface SettingsMenu extends PlayerMenu {
  /** Leave a submenu (Esc). False when already at the main list. */
  back(): boolean;
}

type Attrs = Record<string, string>;

export function createSettingsMenu(d: SettingsDeps): SettingsMenu {
  const menu = createMenu('tide-pmset', 'Playback settings', d.onOpenChange);
  const mainList = h('div', { class: 'tide-pm-list' });
  const main = h('div', { class: 'tide-pmset-pane tide-pmset-main' }, h('h6', { class: 'tide-pm-h6' }, 'SETTINGS'), mainList);
  const subTitle = h('b', {});
  const subList = h('div', { class: 'tide-pm-list' });
  const backBtn = h('button', { class: 'tide-pmset-back', type: 'button', 'aria-label': 'Back' }, icon('chevron_left'));
  const sub = h('div', { class: 'tide-pmset-pane tide-pmset-sub' }, h('div', { class: 'tide-pmset-subhd' }, backBtn, subTitle), subList);
  const panes = h('div', { class: 'tide-pmset-panes' }, main, sub);
  menu.el.append(panes);

  let rows: StockOption[] = [];
  let failed = false;
  let drilled: string | null = null;
  let gen = 0;

  const opt = (attrs: Attrs, iconName: string | null, label: string, small: string, right: Node[], on = false) =>
    h('button', { class: `tide-pm-opt${on ? ' on' : ''}`, type: 'button', ...attrs },
      iconName ? icon(iconName, 'tide-pm-ic') : null,
      h('span', { class: 'tide-pm-lb' }, label, small ? h('small', {}, small) : null), ...right);
  const chevron = () => icon('chevron_right', 'tide-pm-chev');
  const check = () => icon('check', 'tide-pm-ck');
  const audioValue = () => {
    const a = d.audio();
    const t = a.tracks.find((x) => x.index === a.current);
    return t ? [t.label, t.sub.split(' · ').pop()].filter(Boolean).join(' · ') : '';
  };
  /** The box keeps the main list's height; submenus scroll inside it (transform-only slide). */
  const measure = () => {
    main.style.position = 'static';
    const hgt = main.offsetHeight;
    main.style.position = '';
    if (hgt > 0) panes.style.setProperty('--tide-pm-h', `${hgt}px`);
  };
  const renderMain = () => {
    const items: HTMLElement[] = [];
    if (d.audio().tracks.length) items.push(opt({ 'data-go': 'audio' }, ROW_ICONS.audio!, 'Audio', '', [h('span', { class: 'tide-pm-val' }, audioValue()), chevron()]));
    for (const r of rows) {
      if (HIDDEN_ROWS.has(r.id)) continue;
      if (r.id === 'stats') {
        const on = d.statsOn();
        items.push(opt({ 'data-toggle': 'stats', role: 'switch', 'aria-checked': String(on) }, ROW_ICONS.stats!, r.text, '', [h('span', { class: 'tide-pm-toggle' }, h('i', {}))], on));
        continue;
      }
      items.push(opt({ 'data-go': r.id }, ROW_ICONS[r.id] ?? 'tune', r.text, '', [h('span', { class: 'tide-pm-val' }, r.aside), chevron()]));
    }
    if (failed) items.push(opt({ 'data-stock': '' }, 'open_in_new', 'Open default menu', '', []));
    mainList.replaceChildren(...items);
    measure();
  };
  const refresh = async () => {
    const g = ++gen;
    try {
      const r = await d.stock.rows();
      if (g !== gen) return;
      rows = r;
      failed = false;
    } catch {
      if (g !== gen) return;
      failed = true;
    }
    renderMain();
  };
  const showSub = (title: string, nodes: HTMLElement[]) => { subTitle.textContent = title; subList.replaceChildren(...nodes); };
  const back = (): boolean => {
    if (!drilled) return false;
    drilled = null;
    menu.el.classList.remove('drill');
    return true;

    drilled = id;

      return;

      const options = await d.stock.options(id);
      if (drilled !== id) return;
      showSub(title, options.map((o) => opt({ 'data-pick': o.id }, null, o.text, o.aside, [check()], o.selected)));
    } catch {
      if (drilled !== id) return;
      failed = true;
      back();
      renderMain();
    }
  };

  menu.el.addEventListener('click', (e) => {
    const t = (e.target as Element).closest<HTMLElement>('[data-go], [data-pick], [data-toggle], [data-stock], .tide-pmset-back');
    if (!t) return;
    if (t.matches('.tide-pmset-back')) { back(); return; }
    if (t.dataset.go) { void drill(t.dataset.go); return; }
    if (t.dataset.stock !== undefined) { menu.close(); back(); d.openStock(); return; }
    if (t.dataset.toggle === 'stats') {
      d.stock.run('stats').then(() => setTimeout(renderMain, 300), () => { failed = true; renderMain(); });
      return;
    }
    const id = drilled;
    const pick = t.dataset.pick;
    if (!id || pick === undefined) return;
    subList.querySelectorAll('.tide-pm-opt').forEach((x) => x.classList.toggle('on', x === t));
    if (id === 'audio') d.pickAudio(Number(pick));
    else d.stock.pick(id, pick).then(refresh, () => { failed = true; renderMain(); });
    renderMain();
    setTimeout(() => { if (drilled === id) back(); }, BACK_MS);
  });

  return {
    el: menu.el,
    open(anchor) { back(); renderMain(); menu.open(anchor); void refresh(); },
    close() { menu.close(); back(); },
    isOpen: menu.isOpen,
    back,
  };
}
```

```ts
import { api, getSession } from '../api/client';
import { getItem } from '../api/item';

export interface Lang { code: string; name: string }
export interface RemoteSub { id: string; name: string; format: string; provider: string; downloads: number }
export interface Culture { Name: string; DisplayName: string; TwoLetterISOLanguageName: string; ThreeLetterISOLanguageName: string; ThreeLetterISOLanguageNames?: string[] }
export interface OnlineSubs {
  providers: string[];
  /** The user's subtitle language preference, else the UI language, else English. */
  defaultLang: Lang;
  resolveLang(q: string): Promise<Lang | null>;
  search(code: string, nameFilter?: string): Promise<RemoteSub[]>;
  /** Downloads to the item and resolves with the new subtitle stream index. */
  download(sub: RemoteSub): Promise<number>;
}
export const DOWNLOAD_WAIT_MS = 10_000;

let cultures: Promise<Culture[]> | null = null;
const getCultures = () => (cultures ??= api<Culture[]>('/Localization/Cultures').catch((e) => { cultures = null; throw e; }));

export function matchCulture(list: Culture[], q: string): Lang | null {
  const s = q.trim().toLowerCase();
  if (s.length < 2) return null;
  const lang = (c: Culture): Lang => ({ code: c.ThreeLetterISOLanguageName, name: c.DisplayName || c.Name });
  const exact = list.find((c) => [c.TwoLetterISOLanguageName, c.ThreeLetterISOLanguageName, ...(c.ThreeLetterISOLanguageNames ?? []), c.DisplayName, c.Name]
    .some((x) => x?.toLowerCase() === s));
  if (exact) return lang(exact);
  const prefix = list.find((c) => [c.DisplayName, c.Name].some((x) => x?.toLowerCase().startsWith(s)));
  return prefix ? lang(prefix) : null;
}

export async function loadOnlineSubs(itemId: string, opts: { now?: () => number; sleep?: (ms: number) => Promise<void> } = {}): Promise<OnlineSubs | null> {
  const now = opts.now ?? Date.now;
  const sleep = opts.sleep ?? ((ms: number) => new Promise<void>((r) => setTimeout(r, ms)));
  const cap = await api<{ canSearch: boolean; providers: string[] }>('/Tide/Subtitles/Capability', { query: { itemId } }).catch(() => null);
  if (!cap?.canSearch) return null;
  const list = await getCultures().catch(() => [] as Culture[]);
  const pref = await api<{ Configuration?: { SubtitleLanguagePreference?: string } }>(`/Users/${getSession()?.userId ?? ''}`)
    .then((u) => u?.Configuration?.SubtitleLanguagePreference ?? '').catch(() => '');
  const ui = (typeof navigator !== 'undefined' ? navigator.language : 'en').split('-')[0] ?? 'en';
  const defaultLang = (pref ? matchCulture(list, pref) : null) ?? matchCulture(list, ui) ?? { code: 'eng', name: 'English' };
  const subtitleIndexes = async () => new Set(((await getItem(itemId)).MediaSources?.[0]?.MediaStreams ?? [])
    .filter((s) => s.Type === 'Subtitle').map((s) => s.Index ?? -1));
  return {
    providers: cap.providers,
    defaultLang,
    async resolveLang(q) { return matchCulture(await getCultures().catch(() => list), q); },
    async search(code, nameFilter) {
      type R = { Id: string; Name?: string; Format?: string; ProviderName?: string; DownloadCount?: number };
      const r = await api<R[]>(`/Items/${itemId}/RemoteSearch/Subtitles/${encodeURIComponent(code)}`, { query: { isPerfectMatch: false }, timeoutMs: 30_000 });
      const f = nameFilter?.trim().toLowerCase();
      return (r ?? [])
        .map((x) => ({ id: x.Id, name: x.Name ?? '', format: (x.Format ?? '').toUpperCase(), provider: x.ProviderName ?? '', downloads: x.DownloadCount ?? 0 }))
        .filter((x) => !f || x.name.toLowerCase().includes(f));
    },
    async download(sub) {
      const before = await subtitleIndexes();
      await api(`/Items/${itemId}/RemoteSearch/Subtitles/${encodeURIComponent(sub.id)}`, { method: 'POST', timeoutMs: 30_000 });
      const t0 = now();
      while (now() - t0 < DOWNLOAD_WAIT_MS) {
        const added = [...(await subtitleIndexes())].find((i) => !before.has(i));
        if (added !== undefined) return added;
        await sleep(1000);
      }
      throw new Error('downloaded subtitle did not appear');
    },
  };
}
```

```ts
import { h, icon } from '../ui/dom';
import { createMenu, type PlayerMenu } from './menu';
import type { Track } from './tracks';
import type { Lang, OnlineSubs, RemoteSub } from './onlineSubs';

export type SubSize = 'S' | 'M' | 'L' | 'XL';
export const SIZES: SubSize[] = ['S', 'M', 'L', 'XL'];
export const TIMING_STEP = 0.1;

export interface SubtitlesDeps {
  tracks(): { list: Track[]; current: number | null };
  /** null = Off. */
  pick(index: number | null): void;
  size(): SubSize;
  setSize(s: SubSize): void;
  /** Stock subtitle offset (player/stockMenu.ts createSubOffset), null when not offered. */
  timing: { available(): Promise<boolean>; get(): number | null; set(seconds: number): Promise<void> } | null;
  online(): OnlineSubs | null;
  /** A downloaded subtitle arrived as stream `index`: the player restarts playback with it. */
  onDownloaded(index: number): void;
  onOpenChange(open: boolean): void;
}
export interface SubtitlesMenu extends PlayerMenu { refresh(): void }

export function filterTracks(list: Track[], q: string): Track[] {
  const s = q.trim().toLowerCase();
  return s ? list.filter((t) => `${t.label} ${t.sub}`.toLowerCase().includes(s)) : list;
}
export function shortName(t: Track): string {
  const tag = /\bForced\b/.test(t.sub) ? 'Forced' : /\bSDH\b/.test(t.sub) ? 'SDH' : '';
  return tag ? `${t.label} · ${tag}` : t.label;
}
export const fmtOffset = (s: number): string => `${s > 0 ? '+' : ''}${s.toFixed(1)} s`;

type Attrs = Record<string, string>;

export function createSubtitlesMenu(d: SubtitlesDeps): SubtitlesMenu {
  const menu = createMenu('tide-pmsub', 'Subtitles', d.onOpenChange);
  const input = h('input', { type: 'text', autocomplete: 'off', spellcheck: 'false', 'aria-label': 'Search subtitles' }) as HTMLInputElement;
  const clear = h('button', { class: 'tide-pmsub-clear', type: 'button', 'aria-label': 'Clear', hidden: true }, icon('close'));
  const body = h('div', { class: 'tide-pm-list tide-pmsub-body' });
  const sizes = h('div', { class: 'tide-pmsub-chips' }, ...SIZES.map((s) => h('button', { type: 'button', 'data-size': s }, s)));
  const out = h('output', {}, fmtOffset(0));
  const timingRow = h('div', { class: 'tide-pmsub-row', hidden: true }, h('span', {}, 'Timing'),
    h('div', { class: 'tide-pmsub-step' },
      h('button', { type: 'button', 'data-sync': '-1', 'aria-label': 'Subtitles earlier' }, icon('remove')), out,
      h('button', { type: 'button', 'data-sync': '1', 'aria-label': 'Subtitles later' }, icon('add'))));
  const foot = h('div', { class: 'tide-pmsub-foot' }, h('div', { class: 'tide-pmsub-row' }, h('span', {}, 'Size'), sizes), timingRow);
  menu.el.append(h('div', { class: 'tide-pmsub-search' }, icon('search'), input, clear), body, foot);

  let state: 'idle' | 'loading' | 'done' | 'error' = 'idle';
  let results: RemoteSub[] = [];
  let lang: Lang | null = null;
  const dl = new Map<string, 'busy' | 'ok' | 'err'>();
  let colFile = false;
  let colOnline = false;
  let lastKey = '';

  const row = (attrs: Attrs, label: string, sub: string, on: boolean, right: Node = icon('check', 'tide-pm-ck')) =>
    h('button', { class: `tide-pm-opt${on ? ' on' : ''}`, type: 'button', ...attrs },
      h('span', { class: 'tide-pm-lb' }, label, sub ? h('small', {}, sub) : null), right);
  const head = (key: 'file' | 'online', label: string, n: string, col: boolean, cur: string) =>
    h('button', { class: `tide-pmsub-hd${col ? ' col' : ''}`, type: 'button', 'data-col': key, 'aria-expanded': String(!col) },
      label, h('span', { class: 'tide-pmsub-n' }, n), h('span', { class: 'tide-pmsub-cur' }, cur), icon('expand_more'));
  const find = (text: string) => h('button', { class: 'tide-pm-opt', type: 'button', 'data-find': '' },
    icon('travel_explore', 'tide-pm-ic'), h('span', { class: 'tide-pm-lb' }, text));
  const status = (r: RemoteSub): Node => {
    const s = dl.get(r.id);
    if (s === 'busy') return h('span', { class: 'tide-pm-spin' });
    if (s === 'ok') return icon('check_circle', 'tide-pmsub-ok');
    if (s === 'err') return icon('error', 'tide-pmsub-err');
    return h('span', { class: 'tide-pmsub-dl' }, icon('download'));
  };
  const detail = (r: RemoteSub) => [r.name, r.format, r.provider, r.downloads ? `${r.downloads.toLocaleString('en-US')} downloads` : '']
    .filter(Boolean).join(' · ');

  const renderBody = () => {
    const { list, current } = d.tracks();
    const online = d.online();
    const q = input.value.trim();
    clear.hidden = !q;
    input.placeholder = online ? 'Search tracks or online' : 'Search languages';
    const shown = filterTracks(list, q);
    // Section headers only exist once there is a second (online) section; before that it is a plain list.
    const sections = !!online && (q !== '' || state !== 'idle');
    const cur = list.find((t) => t.index === current);
    const nodes: Node[] = [];
    if (!q) nodes.push(row({ 'data-sub': '-1' }, 'Off', '', current === null));
    if (sections) nodes.push(head('file', 'IN THIS FILE', String(shown.length), colFile, current === null ? 'Off' : cur ? shortName(cur) : ''));
    if (!sections || !colFile) {
      const sec = h('div', { class: 'tide-pmsub-sec' }, ...shown.map((t) => row({ 'data-sub': String(t.index) }, t.label, t.sub, t.index === current)));
      if (q && !shown.length) sec.append(h('div', { class: 'tide-pm-empty' }, `No “${q}” track in this file.`));
      nodes.push(sec);
    }
    if (online && !sections) nodes.push(find('Find subtitles online'));
    if (online && sections) {
      nodes.push(head('online', `ONLINE · ${online.providers.join(', ').toUpperCase()}`, state === 'done' ? String(results.length) : '…',
        colOnline, [...dl.values()].includes('ok') ? 'Downloaded' : ''));
      if (!colOnline) {
        const sec = h('div', { class: 'tide-pmsub-sec' });
        if (state === 'idle') sec.append(find(`Search online for “${q}”`));
        else if (state === 'loading') sec.append(h('div', { class: 'tide-pm-opt' }, h('span', { class: 'tide-pm-spin' }), h('span', { class: 'tide-pm-lb' }, 'Searching…')));
        else if (state === 'error') sec.append(h('div', { class: 'tide-pm-empty' }, 'Online search failed.'), find('Search again'));
        else if (!results.length) sec.append(h('div', { class: 'tide-pm-empty' }, `No ${lang?.name ?? ''} subtitles found.`.replace('No  ', 'No ')));
        else sec.append(...results.map((r) => row({ 'data-dl': r.id }, lang?.name ?? r.name,
          dl.get(r.id) === 'err' ? 'Couldn’t download. Try another.' : detail(r), false, status(r))));
        nodes.push(sec);
      }
    }
    body.replaceChildren(...nodes);
  };
  const renderFoot = () => {
    sizes.querySelectorAll<HTMLElement>('[data-size]').forEach((b) => b.classList.toggle('on', b.dataset.size === d.size()));
    out.textContent = fmtOffset(d.timing?.get() ?? 0);
  };
  const searchOnline = async () => {
    const online = d.online();
    if (!online || state === 'loading') return;
    const q = input.value.trim();
    state = 'loading';
    colFile = true;
    colOnline = false;
    dl.clear();
    renderBody();
    try {
      const resolved = q ? await online.resolveLang(q) : null;
      lang = resolved ?? online.defaultLang;
      results = await online.search(lang.code, q && !resolved ? q : undefined);
      state = 'done';
    } catch {
      state = 'error';
    }
    renderBody();
  };
  const download = async (id: string) => {
    const online = d.online();
    const r = results.find((x) => x.id === id);
    if (!online || !r || dl.get(id) === 'busy' || dl.get(id) === 'ok') return;
    dl.set(id, 'busy');
    renderBody();
    try {
      const index = await online.download(r);
      dl.set(id, 'ok');
      renderBody();
      d.onDownloaded(index);
    } catch {
      dl.set(id, 'err');
      renderBody();
    }
  };

  input.addEventListener('input', () => { state = 'idle'; results = []; dl.clear(); colFile = false; colOnline = false; renderBody(); });
  input.addEventListener('keydown', (e) => {
    if (e.key === 'Enter' && d.online() && input.value.trim()) { e.preventDefault(); void searchOnline(); }
  });
  clear.addEventListener('click', () => { input.value = ''; input.dispatchEvent(new Event('input')); input.focus(); });
  menu.el.addEventListener('click', (e) => {
    const t = (e.target as Element).closest<HTMLElement>('[data-sub], [data-col], [data-find], [data-dl], [data-size], [data-sync]');
    if (!t) return;
    const ds = t.dataset;
    if (ds.sub !== undefined) { const i = Number(ds.sub); d.pick(i < 0 ? null : i); renderBody(); return; }
    if (ds.col) { if (ds.col === 'file') colFile = !colFile; else colOnline = !colOnline; renderBody(); return; }
    if (ds.find !== undefined) { void searchOnline(); return; }
    if (ds.dl) { void download(ds.dl); return; }
    if (ds.size) { d.setSize(ds.size as SubSize); renderFoot(); return; }
    if (ds.sync && d.timing) {
      const v = Math.round(((d.timing.get() ?? 0) + Number(ds.sync) * TIMING_STEP) * 10) / 10;
      out.textContent = fmtOffset(v);
      d.timing.set(v).then(renderFoot, () => { timingRow.hidden = true; });
    }
  });

  const key = () => JSON.stringify([d.tracks(), !!d.online()]);
  return {
    el: menu.el,
    open(anchor) {
      lastKey = key();
      renderBody();
      renderFoot();
      menu.open(anchor);
      if (d.timing) d.timing.available().then((ok) => { timingRow.hidden = !ok; }, () => { timingRow.hidden = true; });
      setTimeout(() => input.focus(), 50);
    },
    close: menu.close,
    isOpen: menu.isOpen,
    refresh() {
      if (!menu.isOpen()) return;
      const k = key();
      if (k === lastKey) return;
      lastKey = k;
      renderBody();
    },
  };
}
```

```ts
export const RECENT_MAX = 8;
const key = (userId: string) => `tide-recent:${userId}`;

export function loadRecent(userId: string): string[] {
  try {
    const v = JSON.parse(localStorage.getItem(key(userId)) ?? '[]') as unknown;
    return Array.isArray(v) ? v.filter((x): x is string => typeof x === 'string' && x.trim() !== '').slice(0, RECENT_MAX) : [];
  } catch {
    return [];
  }
}
function save(userId: string, list: string[]): string[] {
  try { localStorage.setItem(key(userId), JSON.stringify(list)); } catch { /* storage blocked */ }
  return list;
}
export function addRecent(userId: string, q: string): string[] {
  const t = q.trim();
  if (!t) return loadRecent(userId);
  return save(userId, [t, ...loadRecent(userId).filter((x) => x.toLowerCase() !== t.toLowerCase())].slice(0, RECENT_MAX));
}
export function removeRecent(userId: string, q: string): string[] {
  return save(userId, loadRecent(userId).filter((x) => x.toLowerCase() !== q.trim().toLowerCase()));
}
```

```ts
import { api, getSession, imageUrl } from '../api/client';
import type { JfItem } from '../types';

/** Subset of Jellyfin's SearchHint (GET /Search/Hints), also used for genre browse results. */
export interface Hint {
  Id: string; Name: string; Type: string; ProductionYear?: number; RunTimeTicks?: number;
  Series?: string; IndexNumber?: number; ParentIndexNumber?: number; PrimaryImageTag?: string;
  AlbumArtist?: string; Album?: string; AlbumId?: string; AlbumPrimaryImageTag?: string; Artists?: string[]; ChildCount?: number;
}
export type Chip = 'all' | 'movies' | 'shows' | 'episodes' | 'people' | 'music' | 'collections' | 'playlists';
export const CHIPS: { id: Chip; label: string; types: string[] }[] = [
  { id: 'all', label: 'All', types: [] },
  { id: 'movies', label: 'Movies', types: ['Movie'] },
  { id: 'shows', label: 'Shows', types: ['Series'] },
  { id: 'episodes', label: 'Episodes', types: ['Episode'] },
  { id: 'people', label: 'People', types: ['Person'] },
  { id: 'music', label: 'Music', types: ['MusicArtist', 'MusicAlbum', 'Audio'] },
  { id: 'collections', label: 'Collections', types: ['BoxSet'] },
  { id: 'playlists', label: 'Playlists', types: ['Playlist'] },
];
const chip = (id: Chip) => CHIPS.find((c) => c.id === id)!;
/** Result groups in display order (spec 2: Shows, Movies, Episodes, People, Music, Collections, Playlists). */
export const GROUPS = (['shows', 'movies', 'episodes', 'people', 'music', 'collections', 'playlists'] as const)
  .map((id) => ({ id, title: chip(id).label, types: chip(id).types }));
export const PER_GROUP = 6;
/** Shift+Enter / the Play button: video types only (music opens its page). */
export const PLAYABLE = new Set(['Movie', 'Episode', 'Series']);
export interface Grouped { top: Hint | null; groups: { id: Chip; title: string; items: Hint[] }[]; counts: Record<Chip, number> }

export function groupHints(hints: Hint[], selected: Chip): Grouped {
  const counts = { all: hints.length } as Record<Chip, number>;
  for (const g of GROUPS) counts[g.id] = hints.filter((x) => g.types.includes(x.Type)).length;
  if (selected !== 'all') {
    const c = chip(selected);
    return { top: null, groups: [{ id: selected, title: c.label, items: hints.filter((x) => c.types.includes(x.Type)) }], counts };
  }
  const [top = null, ...rest] = hints;
  const groups = GROUPS.map((g) => ({ id: g.id as Chip, title: g.title, items: rest.filter((x) => g.types.includes(x.Type)).slice(0, PER_GROUP) }))
    .filter((g) => g.items.length > 0);
  return { top, groups, counts };
}

/** With includeItemTypes set, Jellyfin only returns people / artists when Person / MusicArtist are listed too. */
export const SEARCH_TYPES = 'Movie,Series,Episode,Person,MusicArtist,MusicAlbum,Audio,BoxSet,Playlist';

export async function searchHints(q: string, signal?: AbortSignal): Promise<Hint[]> {
  const r = await api<{ SearchHints?: Hint[] }>('/Search/Hints', {
    query: { searchTerm: q, limit: 40, includePeople: true, includeArtists: true, includeMedia: true, includeItemTypes: SEARCH_TYPES, userId: getSession()?.userId },
    signal,
  });
  return r?.SearchHints ?? [];
}

export interface GenreTile { id: string; name: string; image: string | null }

/** The n genres with the most movies and shows; each tile shows a random backdrop from that genre. */
export async function topGenres(n = 6): Promise<GenreTile[]> {
  const userId = getSession()?.userId;
  const r = await api<{ Items?: { Id: string; Name: string; ChildCount?: number }[] }>('/Genres', { query: { userId, Recursive: true, IncludeItemTypes: 'Movie,Series' } });
  const top = [...(r?.Items ?? [])].sort((a, b) => (b.ChildCount ?? 0) - (a.ChildCount ?? 0)).slice(0, n);
  return Promise.all(top.map(async (g) => {
    const it = await api<{ Items?: { Id: string; BackdropImageTags?: string[] }[] }>('/Items', {
      query: { userId, Recursive: true, GenreIds: g.Id, IncludeItemTypes: 'Movie,Series', ImageTypes: 'Backdrop', SortBy: 'Random', Limit: 1 },
    }).catch(() => null);
    const pick = it?.Items?.[0];
    return { id: g.Id, name: g.Name, image: pick ? imageUrl(pick.Id, 'Backdrop/0', 500, pick.BackdropImageTags?.[0]) : null };
  }));
}

}
```

```ts
import './search.css';
import { getSession, imageUrl } from '../api/client';
import { openDetails, play } from '../api/actions';
import { getNextUp } from '../api/item';
import { fmtRuntime, h, icon } from '../ui/dom';
import { CHIPS, genreTitles, groupHints, PLAYABLE, searchHints, topGenres, type Chip, type GenreTile, type Hint } from './searchApi';
import { addRecent, loadRecent, removeRecent } from './recent';

export const DEBOUNCE_MS = 120;
const CACHE_MAX = 20;
export const TYPE_LABEL: Record<string, string> = {
  Movie: 'Movie', Series: 'Show', Episode: 'Episode', Person: 'Person', MusicArtist: 'Artist', MusicAlbum: 'Album', Audio: 'Song', BoxSet: 'Collection', Playlist: 'Playlist',
};
export interface SearchDialog { el: HTMLElement; open(): void; close(): void; isOpen(): boolean }
export interface SearchDeps {
  search?: (q: string, signal?: AbortSignal) => Promise<Hint[]>;
  genres?: () => Promise<GenreTile[]>;
  genreTitles?: (id: string) => Promise<Hint[]>;
  userId?: () => string;
}

export function subline(x: Hint): string {
  const year = x.ProductionYear ? String(x.ProductionYear) : '';
  const join = (...p: (string | null | undefined)[]) => p.filter(Boolean).join(' · ');
  switch (x.Type) {
    case 'Movie': return join(year, fmtRuntime(x.RunTimeTicks));
    case 'Series': return join(year, x.ChildCount ? `${x.ChildCount} season${x.ChildCount === 1 ? '' : 's'}` : '');
    case 'Episode': return join(x.Series, x.ParentIndexNumber != null && x.IndexNumber != null ? `S${x.ParentIndexNumber} E${x.IndexNumber}` : '', fmtRuntime(x.RunTimeTicks));
    case 'MusicAlbum': return join(x.AlbumArtist ?? x.Artists?.[0], year);
    case 'Audio': return join(x.AlbumArtist ?? x.Artists?.[0], x.Album);
    default: return join(TYPE_LABEL[x.Type], year);
  }
}

function highlight(text: string, q: string): (string | HTMLElement)[] {
  const i = q ? text.toLowerCase().indexOf(q.toLowerCase()) : -1;
  return i < 0 ? [text] : [text.slice(0, i), h('mark', {}, text.slice(i, i + q.length)), text.slice(i + q.length)];
}

function thumb(x: Hint, big = false): HTMLElement {
  const kind = x.Type === 'Episode' ? 'ep' : x.Type === 'Person' || x.Type === 'MusicArtist' ? 'pe' : ['MusicAlbum', 'Audio', 'Playlist'].includes(x.Type) ? 'sq' : 'po';
  const el = h('i', { class: `tide-sd-th ${kind}` });
  const id = x.Type === 'Audio' && x.AlbumId ? x.AlbumId : x.Id;
  const tag = x.Type === 'Audio' && x.AlbumId ? x.AlbumPrimaryImageTag : x.PrimaryImageTag;
  if (tag) el.style.backgroundImage = `url("${imageUrl(id, 'Primary', big ? 300 : 160, tag)}")`;
  return el;
}

const keyHint = (keys: string[], label: string) => h('span', {}, ...keys.map((k) => h('kbd', {}, k)), ` ${label}`);

export function createSearchDialog(deps: SearchDeps = {}): SearchDialog {
  const search = deps.search ?? searchHints;
  const genres = deps.genres ?? topGenres;
  const titlesOf = deps.genreTitles ?? genreTitles;
  const uid = deps.userId ?? (() => getSession()?.userId ?? '');

  const input = h('input', { class: 'tide-sd-q', type: 'text', placeholder: 'Search movies, shows, episodes, people, music', autocomplete: 'off', spellcheck: 'false', 'aria-label': 'Search' }) as HTMLInputElement;
  const clear = h('button', { class: 'tide-sd-clear', type: 'button', 'aria-label': 'Clear', hidden: true }, icon('close'));
  const esc = h('kbd', { class: 'tide-sd-esc' }, 'Esc');
  const chipsBox = h('div', { class: 'tide-sd-chips' });
  const body = h('div', { class: 'tide-sd-body' });
  const foot = h('div', { class: 'tide-sd-foot' }, keyHint(['↑', '↓'], 'move'), keyHint(['Enter'], 'open'), keyHint(['Shift', 'Enter'], 'play'), h('span', { class: 'tide-sd-sp' }), keyHint(['Esc'], 'close'));
  const scrim = h('div', { class: 'tide-sd-scrim' });
  const panel = h('div', { class: 'tide-sd', role: 'dialog', 'aria-modal': 'true', 'aria-label': 'Search' },
    h('div', { class: 'tide-sd-in' }, icon('search'), input, clear, esc), chipsBox, body, foot);
  const el = h('div', { class: 'tide-sd-wrap', 'aria-hidden': 'true' }, scrim, panel);

  let open = false;
  let chip: Chip = 'all';
  let hints: Hint[] = [];
  let order: Hint[] = [];
  let sel = 0;
  let timer: ReturnType<typeof setTimeout> | undefined;
  let ctrl: AbortController | null = null;
  let genre: { id: string; name: string } | null = null;
  let tiles: GenreTile[] | null = null;
  let returnFocus: HTMLElement | null = null;
  const cache = new Map<string, Hint[]>();

  const row = (x: Hint, i: number, q: string) => h('button', { class: `tide-sd-row${i === sel ? ' sel' : ''}`, type: 'button', 'data-i': String(i) },
    thumb(x), h('span', { class: 'tide-sd-tt' }, h('b', {}, ...highlight(x.Name, q)), h('small', {}, subline(x))),
    h('span', { class: 'tide-sd-ty' }, TYPE_LABEL[x.Type] ?? x.Type), icon('arrow_forward', 'tide-sd-go'));

  const renderEmpty = () => {
    const recent = loadRecent(uid());
    const nodes: Node[] = [];
    if (recent.length) {
      nodes.push(h('div', { class: 'tide-sd-hd' }, 'RECENT'), ...recent.map((r) => h('div', { class: 'tide-sd-recent', role: 'button', tabindex: '0', 'data-recent': r },
        icon('history'), h('span', { class: 'tide-sd-rl' }, r), h('button', { class: 'tide-sd-rx', type: 'button', 'aria-label': `Remove ${r}`, 'data-recent-x': r }, icon('close')))));
    }
    if (tiles?.length) {
      nodes.push(h('div', { class: 'tide-sd-hd' }, 'BROWSE'), h('div', { class: 'tide-sd-genres' }, ...tiles.map((t) => {
        const tile = h('button', { class: 'tide-sd-gt', type: 'button', 'data-genre': t.id, 'data-name': t.name }, h('span', {}, t.name));
        if (t.image) tile.style.backgroundImage = `url("${t.image}")`;
        return tile;
      })));
    }
    order = [];
    chipsBox.replaceChildren();
    body.replaceChildren(...nodes);
  };

  const render = () => {
    const q = input.value.trim();
    clear.hidden = !q;
    esc.hidden = !!q;
    if (!q && !genre) { renderEmpty(); return; }
    if (genre) {
      order = hints;
      chipsBox.replaceChildren();
      body.replaceChildren(h('div', { class: 'tide-sd-hd' }, genre.name.toUpperCase()), ...hints.map((x, i) => row(x, i, '')));
      return;
    }
    const g = groupHints(hints, chip);
    chipsBox.replaceChildren(...CHIPS.filter((c) => c.id === 'all' || g.counts[c.id] > 0).map((c) =>
      h('button', { class: `tide-sd-chip${c.id === chip ? ' on' : ''}`, type: 'button', 'data-chip': c.id }, c.label, h('span', { class: 'tide-sd-n' }, String(g.counts[c.id] ?? 0)))));
    if (!hints.length) { order = []; body.replaceChildren(h('div', { class: 'tide-sd-empty' }, `No results for “${q}”.`)); return; }
    order = [...(g.top ? [g.top] : []), ...g.groups.flatMap((x) => x.items)];
    sel = Math.min(sel, Math.max(0, order.length - 1));
    const nodes: Node[] = [];
    let i = 0;
    if (g.top) {
      const t = g.top;
      nodes.push(h('div', { class: 'tide-sd-hd' }, 'TOP RESULT'), h('div', { class: `tide-sd-row tide-sd-top${sel === 0 ? ' sel' : ''}`, role: 'button', tabindex: '-1', 'data-i': '0' },
        thumb(t, true), h('span', { class: 'tide-sd-tt' }, h('b', {}, ...highlight(t.Name, q)), h('small', {}, [TYPE_LABEL[t.Type], subline(t)].filter(Boolean).join(' · '))),
        PLAYABLE.has(t.Type) ? h('button', { class: 'tide-sd-play', type: 'button', 'data-play': '0' }, icon('play_arrow'), 'Play') : null));
      i = 1;
    }
    for (const grp of g.groups) {
      if (chip === 'all') nodes.push(h('div', { class: 'tide-sd-hd' }, grp.title.toUpperCase()));
      for (const x of grp.items) nodes.push(row(x, i++, q));
    }
    body.replaceChildren(...nodes);
  };

  const updateSel = () => {
    body.querySelectorAll<HTMLElement>('[data-i]').forEach((r) => r.classList.toggle('sel', Number(r.dataset.i) === sel));
    body.querySelector<HTMLElement>('.sel')?.scrollIntoView?.({ block: 'nearest' });
  };

  const runSearch = (q: string) => {
    const hit = cache.get(q);
    if (hit) { hints = hit; sel = 0; render(); return; }
    ctrl?.abort();
    const c = new AbortController();
    ctrl = c;
    search(q, c.signal).then((r) => {
      cache.set(q, r);
      if (cache.size > CACHE_MAX) cache.delete(cache.keys().next().value!);
      if (c.signal.aborted || input.value.trim() !== q) return;
      hints = r;
      sel = 0;
      render();
    }).catch(() => { /* aborted or offline: keep the last results */ });
  };

  const close = () => {
    if (!open) return;
    open = false;
    el.classList.remove('open');
    el.setAttribute('aria-hidden', 'true');
    document.documentElement.classList.remove('tide-sd-on');
    ctrl?.abort();
    if (timer) clearTimeout(timer);
    returnFocus?.focus?.();
  };

  const activate = async (x: Hint | undefined, playIt: boolean) => {
    if (!x) return;
    const q = input.value.trim();
    if (q) addRecent(uid(), q);
    close();
    if (playIt && PLAYABLE.has(x.Type)) {
      if (x.Type === 'Series') {
        const nu = await getNextUp(x.Id).catch(() => null);
        void play(nu?.Id ?? x.Id);
      } else void play(x.Id);
      return;
    }
    openDetails(x.Id);
  };

  input.addEventListener('input', () => {
    genre = null;
    chip = 'all';
    sel = 0;
    const q = input.value.trim();
    if (timer) clearTimeout(timer);
    if (!q) { ctrl?.abort(); hints = []; render(); return; }
    timer = setTimeout(() => runSearch(q), DEBOUNCE_MS);
  });
  input.addEventListener('keydown', (e) => {
    if (e.key === 'Escape') { e.preventDefault(); e.stopPropagation(); close(); return; }
    if (e.key === 'ArrowDown' || e.key === 'ArrowUp') {
      e.preventDefault();
      if (!order.length) return;
      sel = (sel + (e.key === 'ArrowDown' ? 1 : -1) + order.length) % order.length;
      updateSel();
      return;
    }
    if (e.key === 'Enter') { e.preventDefault(); void activate(order[sel], e.shiftKey); }
  });
  clear.addEventListener('click', () => { input.value = ''; input.dispatchEvent(new Event('input')); input.focus(); });
  scrim.addEventListener('click', close);
  panel.addEventListener('click', (e) => {
    const t = e.target as Element;
    const x = t.closest<HTMLElement>('[data-recent-x]');
    if (x) { e.stopPropagation(); removeRecent(uid(), x.dataset.recentX!); render(); input.focus(); return; }
    const r = t.closest<HTMLElement>('[data-recent]');
    if (r) { input.value = r.dataset.recent!; input.dispatchEvent(new Event('input')); input.focus(); return; }
    const gt = t.closest<HTMLElement>('[data-genre]');
    if (gt) {
      const g = { id: gt.dataset.genre!, name: gt.dataset.name ?? '' };
      genre = g;
      hints = [];
      sel = 0;
      titlesOf(g.id).then((list) => { if (genre?.id === g.id) { hints = list; render(); } }).catch(() => {});
      render();
      input.focus();
      return;
    }
    const c = t.closest<HTMLElement>('[data-chip]');
    if (c) { chip = c.dataset.chip as Chip; sel = 0; render(); input.focus(); return; }
    const p = t.closest<HTMLElement>('[data-play]');
    if (p) { void activate(order[Number(p.dataset.play)], true); return; }
    const rowEl = t.closest<HTMLElement>('[data-i]');
    if (rowEl) void activate(order[Number(rowEl.dataset.i)], false);
  });
  body.addEventListener('mousemove', (e) => {
    const r = (e.target as Element).closest<HTMLElement>('[data-i]');
    if (r && Number(r.dataset.i) !== sel) { sel = Number(r.dataset.i); updateSel(); }
  });
  document.addEventListener('keydown', (e) => { if (open && e.key === 'Escape') { e.preventDefault(); close(); } });

  return {
    el,
    open() {
      if (open) return;
      open = true;
      returnFocus = document.activeElement as HTMLElement | null;
      input.value = '';
      chip = 'all';
      hints = [];
      genre = null;
      sel = 0;
      render();
      el.classList.add('open');
      el.removeAttribute('aria-hidden');
      document.documentElement.classList.add('tide-sd-on');
      if (!tiles) genres().then((t) => { tiles = t; if (open && !input.value.trim() && !genre) render(); }).catch(() => { tiles = []; });
      setTimeout(() => input.focus(), 30);
    },
    close,
    isOpen: () => open,
  };
}
```

```ts
import { createSearchDialog, type SearchDialog } from './dialog';
import { onLocationChange } from '../router/location';
import { ROUTES } from '../router/selectors';
import type { ClientConfig } from '../types';

/** The stock app-bar search button is `a[href="#/search"]` in 12.4; `.headerSearchButton` on the legacy header. */
export const SEARCH_LINK = 'a[href="#/search"], .headerSearchButton';
export const isSearchRoute = (hash: string = location.hash): boolean => /^#\/search(\?|$)/.test(hash);
const typing = (t: EventTarget | null) => !!(t as Element | null)?.closest?.('input, textarea, select, [contenteditable]:not([contenteditable="false"])');

export function initSearch(cfg: ClientConfig, make: () => SearchDialog = createSearchDialog): () => void {
  if (cfg.enableSearch === false) return () => {};
  let dialog: SearchDialog | null = null;
  const get = () => {
    if (!dialog) { dialog = make(); if (!dialog.el.isConnected) document.body.append(dialog.el); }
    return dialog;
  };
  let lastHash = isSearchRoute() ? '#/home' : location.hash || '#/home';

  // Capture phase on document: runs before React's listeners on the app root, so the route never changes.
  const onClick = (e: MouseEvent) => {
    const a = (e.target as Element | null)?.closest?.(SEARCH_LINK);
    if (!a || e.button !== 0 || e.ctrlKey || e.metaKey || e.shiftKey) return;
    e.preventDefault();
    e.stopPropagation();
    get().open();
  };
  const onKey = (e: KeyboardEvent) => {
    if (ROUTES.isPlayer() || typing(e.target) || dialog?.isOpen()) return;
    const k = e.key.toLowerCase();
    if ((e.key === '/' && !e.ctrlKey && !e.metaKey && !e.altKey) || (k === 'k' && (e.ctrlKey || e.metaKey))) {
      e.preventDefault();
      get().open();
    }
  };
  /** Someone landed on the stock search page (deep link, phone tab bar...): go back to where they were, open the dialog. */
  const onRoute = () => {
    if (!isSearchRoute()) { lastHash = location.hash || '#/home'; return; }
    location.replace(`${location.pathname}${location.search}${lastHash}`);
    get().open();
  };
  document.addEventListener('click', onClick, true);
  document.addEventListener('keydown', onKey);
  const stopRoute = onLocationChange(onRoute);
  if (isSearchRoute()) onRoute();
  return () => {
    document.removeEventListener('click', onClick, true);
    document.removeEventListener('keydown', onKey);
    stopRoute();
    dialog?.close();
    dialog?.el.remove();
  };
}
```

```ts
import { SELECTORS } from '../router/selectors';

/**
 * F1 · C3 top bar: library links show their icon only (the current one is a white pill with its name). Their label is
 * a bare text node inside the MUI button: copy it to `data-tide-label` (CSS tooltip) and `aria-label`.
 */
export function labelNavLinks(root: ParentNode = document): void {
  root.querySelectorAll<HTMLAnchorElement>(`${SELECTORS.appBar} .MuiToolbar-root > .MuiStack-root > a.MuiButton-root:not([href="#/"])`).forEach((a) => {
    const label = [...a.childNodes].filter((n) => n.nodeType === Node.TEXT_NODE).map((n) => n.textContent ?? '').join('').trim();
    if (!label) return;
    if (a.dataset.tideLabel !== label) a.dataset.tideLabel = label;
    if (a.getAttribute('aria-label') !== label) a.setAttribute('aria-label', label);
  });
}
```
