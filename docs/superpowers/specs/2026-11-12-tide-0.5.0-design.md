# Tide 0.5.0: player menus, search dialog, top bar

Three independent parts in one release. They were chosen in the companion prototypes (`player-menus.html`, `search.html`, `navbar.html`):

| Part | Choice |
|---|---|
| Player settings | **M1** drill-down list |
| Player subtitles | **B**: own menu, search plus online download, collapsible sections |
| Search | **Q1** Spotlight dialog |
| Top bar | **F1** two islands, size **C3** (icon-only libraries) |

## Global constraints (carried over)

**Surfaces**
- Solid surfaces only: panel `#141416`, hover and controls `#2a2a2e`, raised `#3a3a3c`.
- Panel edge is a `0 0 0 1px #2a2a2e` ring plus `0 24px 60px rgba(0,0,0,.6)`. No blur, no see-through panels.
- A dim scrim behind a modal is allowed.

**Motion**
- Transform and opacity only, with curve `cubic-bezier(.22,1,.36,1)`. Never rebuild an animated node per frame.

**Visibility**
- An invisible overlay gets `pointer-events: none`.
- `[hidden]` wins over a component's own `display`.

**Icons**
- Material Symbols Rounded, rendered from the font subset (`web/scripts/icons.mjs`). Every new icon name must be added to the subset, or `iconFont.test.ts` fails.

**Feature flags** (plugin config, default on)
- The player menus fall under the existing `EnablePlayer`.
- Search gets a new `EnableSearch`.
- The top bar is part of the existing theme (`EnableTheme`).

## 1. Player menus

The new menus replace the S3 two-column settings sheet (`player/settingsSheet.ts`).

### 1.1 Shared popover behaviour

- **Placement:** a menu opens above its own button. Its right edge lines up with the button's right edge (measured from the button's rect when it opens), and its bottom sits above the scrubber.
- **One at a time:** Settings, Subtitles and the Episodes shelf are mutually exclusive.
- **Controls stay up:** an open menu pins the controls, so they don't idle-hide.
- **Closing:** outside click or Esc closes the menu. In a settings submenu, Esc goes back to the main list first.
- **Open motion:** opacity 0→1 with `translateY(10px) scale(.97)` → none over .34 s, origin bottom right. Closing takes .2 s.
- **Wheel:** scrolls the menu's lists and never changes volume. The 0.4.3 wheel guard covers `.tide-pmenu`.
- **Phone:** width `min(340px, 100vw - 32px)`, right-aligned with a 16 px gutter.

### 1.2 Settings (M1)

The popover is 340 px wide. The box height is fixed to the main list's height. Submenus slide in from the right (`translateX`) and scroll inside the box.

**Main list rows** (icon, label, current value, chevron):

1. **Audio:** Tide's own row, built from the item's audio streams with the existing `describe()` labels. A pick sends `SetAudioStreamIndex` optimistically, as in 0.4.
2. **Rows from the default player**, read at open time from the stock settings action sheet (`.btnVideoOsdSettings`), in stock order.
   - Label = stock text. Value = stock aside text.
   - Known ids get an icon: `aspectratio`→`aspect_ratio`, `playbackrate`→`speed`, `quality`→`high_quality`, `repeatmode`→`repeat`.
   - An unknown id is shown generically with the `tune` icon and driven the same way. This is how "every option the default has" holds on every device. For example, Jellyfin Desktop lists more aspect ratios than web.
   - `stats` ("Playback info") is a toggle row. It is on while the stock `.playerStats` overlay is visible.
   - `suboffset` is **not** a settings row. It drives **Timing** in the subtitles menu (1.3).

**Submenu:**
- A header with a back chevron and the row title.
- The options are read from the stock submenu sheet: text, plus ✓ where the stock check icon is visible.
- A pick clicks the matching stock option, re-reads the main values, then slides back after 220 ms.

**Stock driver** (`player/stockMenu.ts`):
- While Tide drives the stock sheets, `html.tide-stock-hidden` hides them (`.dialogContainer .actionSheet` and the dialog backdrop get opacity 0 and no pointer events).
- Waits for `.actionSheet.opened` for up to 1.5 s.
- Reads `[data-id]` items: `.actionSheetItemText`, `.actionSheetItemAsideText`, and the selected check.
- Closes the stock sheet without picking. The exact method (backdrop click or the dialog's own history entry) is decided by the plan's probe task. It must never leave the player.
- One queue, so two drives never overlap.
- **On failure (timeout):** the menu shows its last known rows, plus a row **"Open default menu"** that clicks the stock settings button visibly.

**Playback info overlay:** restyle stock `.playerStats` as a solid `#141416` card, radius 16, placed under the header at top-left.

### 1.3 Subtitles (B)

The popover is 300 px wide and shown from the existing subtitles button. The button is visible when the item has subtitle tracks **or** online search is available.

**Search field** (focused on open):
- Filters the file's tracks by label and second line, case-insensitive.
- Placeholder: "Search tracks or online" when online search is available, else "Search languages".

**List:**
- **Off** shows only when the query is empty.
- Then the file's tracks with `describe()` labels, ✓ on the current one.
- A pick sends `SetSubtitleStreamIndex` optimistically, as in 0.4.

**Online search** (only when the capability says `canSearch`):
- **Query empty:** a **"Find subtitles online"** row under the list. It searches the user's subtitle language preference, else the UI language.
- **Query typed:** an **"Online · ⟨provider names⟩"** section with **"Search online for “q”"**.
  - The language is resolved from `q` via `/Localization/Cultures`: case-insensitive match or prefix on display name, name, or 2- or 3-letter code.
  - If `q` is not a language, the default language is searched and results are filtered to names containing `q`.
- **Search:** `GET /Items/{id}/RemoteSearch/Subtitles/{lang3}?isPerfectMatch=false`.
  - Each result row shows the name (release), then format · provider · download count, then a download button.
  - States: spinner while searching, "No subtitles found", and an error row.
- **Download:** `POST /Items/{id}/RemoteSearch/Subtitles/{subtitleId}`, with a spinner on the row.
- **After download:**
  1. Poll the item for up to 10 s until the new external subtitle stream appears.
  2. Restart playback at the current position with that stream: `POST /Sessions/{own}/Playing?playCommand=PlayNow&itemIds=…&startPositionTicks=…&subtitleStreamIndex=…&audioStreamIndex=…&mediaSourceId=…`.
  3. The K1 loading screen shows "Restarting with subtitles…".
- **On failure:** the row shows "Couldn’t download. Try another." and the menu stays open.

**Collapsible sections:**
- Section headers appear only once the online section exists. Before that, the menu is a plain list.
- **"IN THIS FILE · n"** and **"ONLINE · ⟨provider⟩ · n"** are sticky headers with a chevron, and click to toggle.
- A collapsed "In this file" header shows the current pick, e.g. "English · Forced".
- Starting an online search collapses the file tracks and expands Online. Typing in the field expands the file tracks again.
- Collapsing is instant (no height animation). An opening body fades in: opacity plus `translateY(-4px)` → none over .28 s.
- A downloaded subtitle joins "In this file" and becomes current.

**Footer:**
- **Size** S / M / L / XL (the existing `subSize`).
- **Timing** `− value +`: drives the stock subtitle offset (the `suboffset` UI, hidden). The step size and the control used are decided by the plan's probe task. Shown only when the stock settings offer `suboffset`.

**Server:** new `GET /Tide/Subtitles/Capability?itemId=` returns `{ canSearch: bool, providers: string[] }`.
- `canSearch` is true only when `ISubtitleManager.GetSupportedProviders(item)` is not empty **and** the user is an administrator or has `EnableSubtitleManagement`.

## 2. Search (Q1 Spotlight)

The dialog replaces the stock search page.

**Opening:**
- Clicking the app bar search button. The click is intercepted in the capture phase; the selector is confirmed by a probe.
- `/` or Ctrl/⌘+K anywhere outside a text field.
- Navigating to stock `#/search`: the dialog opens and the route returns to where the user came from.
- Never inside the player.

**Layout:**
- A scrim `rgba(0,0,0,.72)` over the page.
- The panel is 720 px wide, top 90 px, max height `min(700px, 100vh - 120px)`, `#141416`, radius 24, ring plus shadow.
- **Input row:** search icon, 22 px semibold field, Esc hint (a clear × once there is text).
- **Type chips** with counts: All, Movies, Shows, Episodes, People, Music, Collections, Playlists. Only types that have results are shown.
- The results body scrolls, with a footer of key hints: ↑ ↓ move · Enter open · Shift+Enter play · Esc close.
- **Open motion:** opacity plus `translate(-50%,-10px) scale(.98)` → none over .42 s. The scrim fades over .3 s.

**Data:**
- `GET /Search/Hints?searchTerm=q&limit=40&includePeople=true&includeArtists=true&includeItemTypes=Movie,Series,Episode,BoxSet,Playlist,MusicAlbum,Audio`.
- Debounce 120 ms. A stale request is aborted (AbortController). The last 20 queries are cached in memory.

**Results:**
- **Top result:** the first hint, as a large row with a 76 px poster (16:9 still for an episode, round photo for a person) and title, type · meta. Playable types get a white **Play** button.
- **Groups, in order:** Shows, Movies, Episodes, People, Music (artists, albums, songs), Collections, Playlists.
  - With All selected: at most 6 per group, under a group heading.
  - With a chip selected: the full list, no heading.
- **Row:** thumb (2:3 poster, 16:9 still, round person, square album), title with the match underlined, second line, type label, and an arrow on hover or selection.

| Type | Second line |
|---|---|
| Movie, Series | year · genre · runtime / seasons |
| Episode | series · S E · runtime |
| Person | role |
| Album | artist · year |
| Song | artist · album |

**Empty state:**
- **Recent:** the last 8 queries per user (`localStorage tide-recent:<userId>`), each removable with ×.
- **Browse:** 6 genre tiles. They are the genres with the most Movies and Series. Each tile's background is a backdrop from that genre.
- Clicking a genre shows its titles in the dialog under the genre name: `/Items?Genres=…&IncludeItemTypes=Movie,Series&Recursive=true&SortBy=CommunityRating`.

**Keyboard:**
- ↑ / ↓ move the selection (wrapping) and keep it scrolled into view.
- Enter opens: Movie, Series and Episode go to Tide's details; other types go to stock details.
- Shift+Enter plays (playable types).
- Esc closes.
- Opening a result closes the dialog and adds the query to Recent.

**Phone (< 700 px):** the panel is full screen (inset 0, radius 0) and the chips scroll sideways.

**Config:** `EnableSearch`, a new plugin config checkbox. When off, the stock search page is untouched.

## 3. Top bar (F1 · C3)

Desktop (≥ 700 px) only. The phone keeps today's bars.

**Structure:** the stock MUI app bar is restyled into two islands. The DOM grouping is confirmed by a probe.
- **Left island:** Jellyfin logo (home) plus the library links.
- **Right island:** action buttons (SyncPlay, cast, search, others) plus the avatar.
- The app bar itself is always transparent. There is no full-width black bar any more.

**Size:**
- Island height 46, radius 23, padding 5 px; outer bar padding 12 px 28 px.
- Logo button 36 px (24 px glyph). Icon buttons 36 px (20 px glyph). Avatar 30 px.

**Libraries:**
- Icon-only 36 px circles, hover `#2a2a2e`.
- The current library is a white pill with icon and name (`padding 0 13px 0 10px`, 14 px semibold). It swaps without a width animation; the label fades in.
- Hovering an icon-only link shows a tooltip below it: solid `#2a2a2e`, 12.5 px, radius 8.

**Fill:**
- Over a hero (home or details, not yet scrolled), the islands have no fill.
- Once `body.tide-scrolled` is set, and on every other page, they become solid `#141416` with ring and shadow.
- The fill is a `::before` layer that fades in with opacity over .35 s.

## Testing

**Unit (vitest)**
- **Stock driver:** reading, picking and closing against a fake stock sheet DOM; timeout fallback; queue order.
- **Settings menu:** rows from stock plus Audio, drill-down, re-read after pick, Esc order, the alignment calculation.
- **Subtitles menu:**
  - filtering;
  - Off visibility;
  - section collapse rules;
  - online search, download and restart, with fetch mocked;
  - language resolution;
  - capability gating.
- **Search:**
  - grouping and order;
  - top result;
  - chips and counts;
  - keyboard;
  - recent storage;
  - debounce and abort;
  - genre browse;
  - opening from `/`, Ctrl+K and the button;
  - `#/search` redirect.
- **Top bar:** island classes and the active library pill.
- **Server (xUnit):** the capability endpoint for admin, permitted, and not-permitted users, with no providers and with providers.

**End-to-end (local 12.4)**
- **Settings:**
  - the stock rows are shown;
  - picking 1.5× changes `video.playbackRate`;
  - aspect ratio changes `object-fit`;
  - Playback info toggles the stats overlay;
  - the stock sheets are never visible.
- **Subtitles:** filter, pick a track, and Timing.
- **Search:**
  - opens from the button and from `/`;
  - typing shows grouped results;
  - Enter opens details;
  - Esc closes;
  - `#/search` opens the dialog.
- **Top bar:** islands are transparent at the top and solid after scrolling; the current library is a pill.

## Out of scope

Library browse, login and profiles, and the admin dashboard each get their own design session. A music player is also out of scope.
